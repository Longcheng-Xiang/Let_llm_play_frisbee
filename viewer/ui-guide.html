This page is a compact reference for the replay viewer controls. Live trials can make paid model calls, so use Start Trial deliberately.

Recommended Default Setup

For the current V2 system, the recommended testing configuration is the viewer default:

  • Version: V2 Awake
  • Model: V4 Flash
  • Thinking: On
  • Frame Upper Limit: 20
  • Throw Score: 100 for deterministic throw trajectory
  • Max Disc Speed: 18 cells/frame
  • Settings Lock: Locked unless intentionally comparing settings

Example cost: the included 19-frame scoring demo cost about $0.112026. New live-run costs vary with awake-player count, output length, cache behavior, and provider pricing.

The game may end before this upper limit because a score, stop request, or another stop condition can finish the run early.

Use other settings only when you are intentionally comparing versions, model behavior, or throw uncertainty.

Trial Setup

Locked / Unlocked
Locked protects the recommended setup. Unlock it to change version, model, thinking, throw score, or max disc speed. Frame Upper Limit stays editable.
Version
Choose V2 Awake for wake/sleep runs, or V1 All Awake to call every player every frame.
Model
Choose the DeepSeek model used for live player decisions.
Thinking
Turns model thinking mode on or off when the selected model supports it.
Frame Upper Limit
Maximum number of frames the live trial may run before stopping.
Throw Score
Use 100 for deterministic throws, or Roster to use each player's configured throw rating.
Max Disc Speed
Caps throw speed in cells per frame.

Run Buttons

Start Trial
Starts a live API-backed run using the current setup controls.
Stop Trial
Stops the run and abandons waiting for active model calls. Already-started provider requests may still finish server-side.
Sample Replay
Loads the included final 19-frame scoring demo.
UI Guide
Opens this guide in a separate page.
HTML Report
Opens the readable report for the latest live log.
Open Log
Loads a local JSONL replay file from disk.

Replay Controls

Prev
Step backward one frame.
Play
Automatically advances frames until the replay ends. Press again to pause.
Next
Step forward one frame.
Speed
Controls playback speed for Play mode.
Timeline
Jump directly to a frame.

Score Strip

Frame
Current replay frame and total loaded frame index.
Possession
Team currently considered to have possession.
Disc
Held player or compact flying-disc position and speed.
Pass
Current committed pass, if private eye contact has been established.
Stall
Remaining stall count when the marker is within marking radius.
Status / Live
Replay/run state, stop reason, running frame, and estimated cost.

Field Marks

Blue / Red Circles
Players. The number labels show matchup pairs: B1 is guarded by R1, and so on.
Yellow Ring
Awake player: the model was called for this player on this frame.
Teal Dashed Ring
Sleeping player moving by stored intent/controller action.
Black Marker
The currently selected player.
Dashed Disc Path
Predicted straight future path of a flying disc.

Inspection Panels

Selected Player
Shows position, role, matchup, attributes, current action, and reason.
Frame Events
Lists simulator events for the current frame.
Players
Click a player chip to select that player.
Disc Trace
Shows disc movement/catch/turnover events for the current frame.
Agent Log
Shows model call status, usage, raw JSON content, returned reasoning, and errors when available.
